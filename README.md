# QtTranslatorApp

Application de bureau développée en **C++** et **Qt 6**, permettant de traduire des mots à la volée vers plusieurs langues grâce à une API REST externe.

## 🚀 Fonctionnalités
- Interface graphique moderne construite avec les Widgets Qt.
- Requêtes réseau asynchrones (`QNetworkAccessManager`) pour ne pas bloquer l'interface.
- Traitement de réponses JSON (`QJsonDocument`).
- Architecture modulaire et propre (séparation en classes).

## 🛠️ Technologies utilisées
- C++17
- Qt 6 (Widgets, Network)
- CMake
- API MyMemory
